# Research brief — Founder ownership math: the primary data

## Question
What do the primary datasets actually say about founder dilution by stage, median exit values, and outcome odds — so the "your 4.8% of a $15M exit" conversation card rests on data, not one viral tweet's back-of-envelope?

## Why it matters for the talk
The levelsio/Turnbull exchange is a killer conversation-starter for an incubator audience (it's literally their situation), and it dovetails with the talk's real thesis: agent leverage changes how far a small team gets before raising. But every number in it is second-hand.

## What we already have
- `sources/tweet-2078604512215134325-founder-ownership-percent.md` — full exchange: Carta medians ~56% → <10% solo by Series E; $1B outcome vs $71M median exit; ~15% acquisition odds; expected ~$960k for one of 4 co-founders; Turnbull's "$15M exit… moved back in with my parents… 4.8%".

## What to find
1. **The exact Carta report** (title, date, URL) with founder-ownership-by-stage medians; quote the table values.
2. **Median exit value**: source for ~$71M (Carta? PitchBook? year?) and the current figure.
3. **Outcome odds**: a citable base rate for VC-backed startup outcomes (acquisition/IPO/shutdown distribution) — Correlation Ventures / PitchBook / AngelList datasets.
4. **The counter-scenario**: data on bootstrapped/small-team outcomes in the agent era — e.g. revenue-per-employee outliers 2025-2026, smallest teams to $10M ARR — the "agents change this math" half of the card.
5. Label clearly what remains levelsio's arithmetic vs sourced data.

## Acceptance
Each figure on the card: exact clickable primary URL + verbatim quote, or the card ships as "one founder's math" opinion framing only.

## Method
Single focused deep-research run; Carta publishes its data reports publicly — find the exact edition.
