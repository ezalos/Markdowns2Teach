## Not cited, and why

- **The r/LocalLLaMA ~24.8-month chart.** Permalink unrecoverable; it is a community chart, which the source bar
  excludes. It was used only to identify a claim worth checking elsewhere, and the check failed — see report §7.
- **Aggregator and SEO blog posts** returned in bulk by search for the cost, quantisation, hardware and EU-provider
  questions (localaimaster, sitepoint, vrlatech, textcortex, edenai, vstorm, abzglobal and similar). None meet the
  source bar; every claim in this report was traced back to the primary measurement instead.
- **Vendor comparative claims.** Scaleway's press release also asserts GLM-5.2 "performs within 1% of Claude Opus
  4.8" on FrontierSWE. That is a vendor comparative claim and is deliberately not used; the report compares models
  only via Artificial Analysis's independently run index.
