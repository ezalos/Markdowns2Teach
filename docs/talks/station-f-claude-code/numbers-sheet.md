3. **Quote column is character-exact** — including curly apostrophes (’), en/em dashes (– —),

5. **Fetch-gate hazards are marked ⚙** — the quote needs tag-stripping, `pdftotext -layout`,

benchmark isn't adequately stressing memory capabilities."*
