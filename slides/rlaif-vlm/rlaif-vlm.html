▸ the_ambition // no humans in the labeling loop03 / 14
three levels of rlaif — we did two, on purpose

Let an AI grade the AI.

Level 1 · did ✓
Offline RLAIF
Train on an existing AI-labeled preference dataset — no live loop. DPO · pairwise A/B · offline
Level 2 · did ✓
Closed-loop RLAIF
Our model writes answers → a separate AI judge grades → we retrain. $0, free judge. The level that earns the name. DPO · pairwise A/B · offline
Level 3 · not yet ✕
Online RL
Reward every rollout live. Needs fast infra and a low-noise reward — our judge flips 20% of verdicts, and level 2 already showed what optimizing that noise does. PPO · online · scalar reward → advantages · KL

How we keep score: held-out preference accuracy — does the model rank the faithful answer above the hallucinated one? 50% = chance (±3 at n=256). Measured, never optimized — that's what makes it evidence, not memorization.

▸ act_01 // the prompts that steered it07 / 14

You steer by prompt.

0
"Keep going." a cron nudge every few minutes so the loop never stalls unattended.
1
"Prove the training is bug-free." the overfit test — loss must start at 0.693 and fall to 0. Caught a "frozen" part still training.
2
"Use the whole GPU — run experiments in parallel." a memory trick (same gradient, ⅓ the footprint) ran 3 trials at once → utilization 40% → 98%.
3
"Reports must interpret the science, not report uptime." every check-in became a diagnosis vs previous runs.
4
"Compute and API are fixed budgets." pre-registered gates + ship-best-checkpoint; a free-tier judge with hard caps → $0 of grading.

▸ act_02 // self-correction10 / 14

It caught three bugs
in its own work.

1
The moving exam. Different experiments were being graded on different test questions. → pinned one shared test set for every run.
2
The unreliable judge. Ask the judge the same question with the two answers swapped, and its verdict flips 20% of the time. → measured the noise, then a 3-vote majority protocol.
3
The contaminated exam. The overnight model scored an impossible 0.887… because the test set had leaked into its training data. → caught in minutes (too good to be true), re-graded clean → 0.723.

The most important agent skill isn't intelligence. It's self-suspicion.

The judge is a separate free vision model — not the one being trained. Push too hard against its noisy verdicts and the model games the judge instead of getting better.

De-noise the feedback (3-vote judge) → the gain returns. The judge's quality is the ceiling.
