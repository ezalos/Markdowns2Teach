SFPart 2 · WhatDefinition
Definition

An agent is a loop

A system that uses tools, repeatedly, with its environment, to reach a goal.

Think

What should I do next to get closer to the goal?

Act

Call a tool. Search, read, write, run a command.

Observe

Read what came back — then decide again.

Not a chatbot. Not a single prompt. A loop that acts, observes, and acts again.

SFPart 2 · WhatChoosing a model
Choosing a model

Cost against capability, and how hard it thinks

What more spending actually buys, per model
Source: METR — expenditure horizon on the NanoGPT speedrun (CC-BY)[1]
  • Each panel is one model. Spend more, get further — until the curve flattens and the next dollar buys almost nothing.[1]
  • METR puts the human cost at about $2,500 per 1% speedup. The best agent reaches an expenditure horizon near $3,300 before flattening.[1]
  • Build on the ceiling while designing; move down in production once your tests prove a cheaper setting is enough. And say the version and the operator — three different “Terminal-Bench” numbers circulate.[2][3]

The model is the smallest decision you make — and the one that changes fastest.

The cost that moved

Bad code is the most expensive
it has ever been

  • “Edit the spec, re-run the compiler, never look at the code” is vibe coding with better branding — each regeneration degrades the codebase.
  • AI compounds in good codebases and drowns in bad ones.

The fundamentals did not stop mattering. They started compounding.

SFPart 3 · Your codebaseLive · the pattern
Live · the pattern

Reach shared understanding before you build

grill-me — a two-line skill
> Use the grilling skill. Build the agent in README.md.
Facts first, then questions.
❓ Q1 — What is actually being delivered here?
➞ (c), weighted toward (a). Build something genuinely runnable, but treat the interview itself as the artifact…
❓ Q2 — Is “we” real?
➞ Invented, but honor it as if real. If it is real, say so now — it moves the PII question from a nice touch to a hard gate.

It interviews you until you share a design — and it refuses to ask anything it could look up itself. That is why it takes four minutes before the first question. Plan mode is “extremely eager to create an asset” instead of reaching understanding.

SFPart 3 · Your codebaseWrap
Part 3 · wrap

Three things that pay twice now

A glossary file

Your domain's terms, generated from your own codebase. Less verbose reasoning, implementations that match the plan. This is context engineering.

Feedback rate

Tests, types and browser access are the agent's sensory organs, not hygiene. Your feedback rate is your speed limit.

Deep modules

Design the interface, delegate the implementation. Agents produce shallow sprawl they then cannot navigate.

Intuition to keep: an agent should not be able to do damage your code would not let a human do — types at the door, constraints at the ledger.[1]
Steal: write the glossary file this week, and add one grill-me skill.
