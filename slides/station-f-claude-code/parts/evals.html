How it matures — rigor grows with complexity

Capability vs behavior — measure both. You do not start at phase 4, and you do not stay at phase 1.

Phase 1

Documented vibe-checks

~10 inputs; human thumbs plus a written justification — the asset you scale later.

Phase 2

Measure to manage

LLM-judge for the subjective, deterministic code scorers for the objective.

Phase 3

Whole-trace & tool calls

Score the full trace; target tool and MCP calls; mock externals, snapshot state.

Phase 4

Auto-discover

Topic-model production to surface failure modes — no longer hand-named.
