So what compounds?

The trend line is not the asset.
The thing you build around the model is.

  • Thread to pull — the Epoch Capabilities Index: 15.5 points a year, on a scale that re-anchors as benchmarks saturate, so it does not run out.[1]
  • And the ceiling — the Remote Labor Index: real paid freelance projects, human-graded, 2.5% → 15.8% automated in under eight months.[2]
Steal this: stop quoting a benchmark you have not checked this month.
