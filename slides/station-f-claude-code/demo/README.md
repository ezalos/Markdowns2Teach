# Support Signal

We are a 6-person B2B SaaS. Every week our support inbox gets ~400 conversations
across Intercom and email. Nobody reads them all. Product decisions get made from
whoever shouted loudest in the last standup.

We want an agent that turns last week's support conversations into a one-page
memo the founders read on Monday morning: what broke, what customers asked for,
and what it would cost us to ignore each item.

## Constraints
- Support data contains customer names and account IDs.
- We have no data engineer.
- Nobody will maintain this if it takes more than an hour a month.
