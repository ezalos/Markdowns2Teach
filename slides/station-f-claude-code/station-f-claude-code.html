PART TWO

The vocabulary,
fixed.

Nine words carry the rest of this talk. If “harness” means two different things in this room, every chapter after this lands differently.
definition

An agent is a loop

A system · that uses tools · repeatedly · with its environment · toward a goal.
think → to answer that, I should search first act search_web("…") observe→ result #2 looks right … repeat until the goal is reached … answer the thing you actually wanted
Not a chatbot. Not a single prompt. A loop that acts, observes, and acts again.
Sources : ReAct (arXiv 2210.03629) · Anthropic — context engineering

Agent = LLM + harness

You buy the model. Everything else is the harness — and the harness is the part you actually control.

the mental model that matters most

What the model actually sees

01One text, rebuilt and re-sent every single turn. The model remembers nothing by itself.

Parallelise reads. Serialise writes.

Right about
writes

CHAPTER THREE

What loops are
actually good at.

“Agents will do our R&D” is the loudest claim in this building. Two controlled studies say exactly where it stops.
the shift

Stop prompting. Build loops.

From “write this for me” — one prompt, one task — to “keep working toward this”: a loop that re-prompts itself until the goal is met.
01A goal. “A loop without a goal is a slop cannon.”
02Context — the fuel: tools, skills, errors, memories. Consumed and replenished, not loaded once.
03Evaluation. The agent verifies, not you. This is the ingredient that makes it unattended.
04An agent to run it — built into the harness now, not hand-rolled. [1][2]
Sources : [1] PostHog — why we're bullish on loops · [2] Claude Code — routines
the good half

Measurably good at hill-climbing

81.7%
of the gap to a human record closed, on the nanoGPT speedrun
153
autonomous runs, 18 frontier models, up to 8 days each — every trace published
If you can already compute the metric, a loop will climb it — cheaply, overnight, and without you. That is a real and immediately available superpower. [1]
Sources : [1] Prime Intellect — measuring autonomous research · the speedrun leaderboard
the wall

Measurably bad at inventing the method

↳Across all 153 runs: “None of the runs produced a fundamentally new method.” [1]
↳Against five months of human world records, three frontier harnesses recovered 8.2–9.3% of the progress — while ~77% of those human records were algorithmic changes. The agents spent their compute tuning hyperparameters. [2]
↳The honest counter-example: AlphaEvolve's 4×4 matrix multiplication in 48 multiplications — independently verified and generalised by outside mathematicians. One artefact. And humans did the verifying. [3][4]
Agents beat human experts 4× at a two-hour budget. Humans win at eight hours, and score 2× at thirty-two. Time is the axis. [5]
Sources : [1] Prime Intellect · [2] NanoGPT-Bench · [3] DeepMind — AlphaEvolve · [4] Tao — exploration at scale · [5] METR RE-Bench
chapter three · wrap

Reward hacking is the failure
you will actually hit

A loop optimises the metric, not the goal. That is the same mechanism as the Hugging Face incident — at your scale, on your metric.

CHAPTER FOUR

The method that makes
a loop converge.

Six steps. What you are building is a skill — or a few — plus the tools it needs and the data it can reach.
the spine

Clarify → Draft → Evaluate → Observe → Improve → Understand

step 1 · clarify

Turn taste into
binary checks

Deep-research what separates a great output from an average one. Take the 20% that carries 80%. Convert it into binary checks that sum to a score. Works best on a task you do well yourself.

step 2 · draft

A to Z beats
a perfect fragment

The smallest thing that runs end to end. Wire the tools and the data access now. Build the checks in from the first run, not later.

Steps 3 to 5 are a loop. You will go round it more than once, and that is the point.
steps 3–5 · the inner loop

Fresh context. Red rows. One bottleneck.

03Evaluate on three fresh examples. Clear the context first — otherwise the conversation does the work, not the skill, and it breaks “mysteriously” tomorrow.
04Observe: criteria down, examples across. A red row is a systematic gap. A red column is a broken example. The average is your one number to move.
05Improve exactly one bottleneck — the most pressing — then stop. A change that does not move the tests does not stay.
Keep the examples in a folder and replay them after every change, forever. They cost nothing today and save a paralysed migration in six months. [1]
Sources : [1] Hamel Husain — your AI product needs evals · Braintrust — the maturity phases of running evals
chapter four · wrap

Step 6 — understand what you built

Thinking is not understanding. A system you cannot explain is a system you cannot fix or defend.
↳Ask the agent to teach you what it built, and to quiz you on it. Have it generate the diagram — it onboards the next person too.
↳Thread to pull: LLM-as-judge, done properly — sample an odd number of times, take the majority, and validate the judge against your own labels before you trust it past 80% agreement. [1]
intuition to keepThe agent did the typing. Make sure you still own the thinking.
Steal: three test cases, in a folder, replayed after every change.
Sources : [1] Hamel Husain — evals

A lesson this agent hit, wrote down, and now re-reads. Readable, greppable, diffable, reviewable in a pull request. The deck you are looking at was built by the agent whose memory this is.
same idea, opposite ergonomics

A folder, or a database?

$ sqlite3 ~/.codex/memories_1.sqlite ".schema" CREATE TABLE stage1_outputs ( thread_id TEXT PRIMARY KEY, raw_memory TEXT NOT NULL, rollout_summary TEXT NOT NULL, usage_count INTEGER, selected_for_phase2 INTEGER NOT NULL DEFAULT 0 );
A two-stage curation pipeline with usage tracking — not a folder you can read. Neither is wrong. But one of them you can review, and hand to a new teammate, on day one.
and it holds up when measured

The threshold, not the winner

↳An agent that writes the conversation to a file and greps it scores 74.0% on the standard memory benchmark — in the same range as the specialised products, and above the full-context baseline. [1]
↳The honest threshold: at ~26k tokens plain full context wins outright; at ~115k memory systems win by 11–24 points. Scale when you cross it, not before. [2]
↳And treat the vendor tables carefully — an audit of that benchmark found 6.4% of the answer key wrong and the judge accepting 62.81% of deliberately wrong answers. [3]
The category is also not six months old, whatever the marketing says. Its founding paper is from October 2023. [4]
