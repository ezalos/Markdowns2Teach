Context:
This diagram illustrates the LiteEmbed method for a research paper on multi-query embedding search methods for production visual retrieval. The diagram should be clear, academic, and publication-quality. LiteEmbed is a technique for optimizing text embeddings to improve retrieval of rare or fine-grained classes. It leverages PCA decomposition of the embedding space to separately handle coarse semantic alignment and fine-grained class separation, producing a plug-and-play replacement text embedding without modifying the visual encoder.

Elements to represent:
1. CLIP text embedding space — The starting point on the left, showing the original high-dimensional space where text embeddings of class names live. In this space, a rare class like "Hermès Birkin in Togo leather" may be poorly positioned: too close to visually confusable classes (other leather handbags) and not well-aligned with its actual visual appearance. The embedding is a frozen CLIP text encoder output.
2. PCA decomposition — The central analytical step. PCA is applied to a set of text embeddings comprising the semantic neighborhood (related coarse classes) and the confusable set (visually similar but semantically distinct classes). The PCA produces principal components ordered by variance explained. Show the principal components as axes, with high-variance components on one end and low-variance components on the other.
3. High-variance principal components — The top PCA dimensions (e.g., the first 50 to 100 components) that capture coarse semantic structure. These dimensions encode broad category-level information: "this is a handbag" versus "this is a shoe" versus "this is a watch." Variation along these axes reflects large-scale semantic differences. In the diagram, show these as a subspace labeled "coarse semantics" with broad category clusters separated along these axes.
4. Low-variance principal components — The bottom PCA dimensions (e.g., the last 100 to 200 components) that encode fine-grained distinctions. These dimensions capture subtle differences that distinguish visually similar items: "Togo leather texture" versus "Epsom leather texture" versus "Swift leather texture." Variation here is small but highly informative for rare class discrimination. Show these as a subspace labeled "fine distinctions" with confusable classes clustered closely.
5. Semantic neighborhood — The set of related coarse classes used to define the PCA basis. For a target class "Hermès Birkin Togo," the semantic neighborhood might include "Hermès Birkin," "Hermès Kelly," "structured leather handbag," and "luxury top-handle bag." These classes share broad semantics with the target and help define the coarse alignment subspace.
6. Confusable set — The set of visually similar classes that must be distinguished from the target. For the Birkin example: "Hermès Birkin Epsom," "Hermès Birkin Swift," "Hermès Garden Party Togo," and "Delvaux Brillant." These share fine-grained visual features and must be separated in the low-variance subspace.
7. Dual-loss optimization — The optimization procedure that produces the new text embedding. Two losses operate simultaneously in different subspaces. The Coarse Alignment Loss operates in the high-variance subspace and pulls the optimized embedding toward the correct coarse semantic region (ensuring it remains recognizable as a "structured leather handbag"). The Fine Separation Loss operates in the low-variance subspace and pushes the embedding away from confusable classes (ensuring "Togo leather" is distinguished from "Epsom leather"). The balance between these losses determines the final embedding position.
8. Resulting optimized embedding — The output on the right: a new text embedding vector that replaces the original CLIP text embedding for the target class. This embedding is a plug-and-play replacement requiring no changes to the visual encoder, the index, or the retrieval pipeline. It simply provides a better target point in embedding space for the rare class.

- Principal: The PCA decomposition splitting the embedding space into high-variance (coarse) and low-variance (fine) subspaces, with the dual-loss optimization operating across both. The visual contrast between the two subspaces and their different roles should dominate.
- Secondary: The semantic neighborhood and confusable set defining the PCA basis. The Coarse Alignment and Fine Separation losses with their respective subspace targets. The before-and-after embedding positions.
- Optional: Concrete example with leather handbag classes. Variance explained plot showing the PCA spectrum. Note about plug-and-play deployment.

Flow:
The diagram flows from left to right in four stages. Stage one (far left): the original CLIP text embeddings of the target class, semantic neighborhood, and confusable set are shown in the original space. Stage two (center-left): PCA is applied to decompose the space, with an axis or spectrum showing high-variance to low-variance components. Stage three (center-right): the dual-loss optimization is shown with the Coarse Alignment Loss pulling the embedding in the high-variance subspace (upward or leftward arrow toward the semantic neighborhood centroid) and the Fine Separation Loss pushing it in the low-variance subspace (arrows pushing away from confusable class embeddings). Stage four (far right): the optimized embedding is shown in its final position, better separated from confusables while remaining aligned with the correct coarse category.

Annotations:
- PCA insight: high-variance principal components encode coarse categorical semantics, low-variance components encode fine-grained distinguishing features
- Coarse Alignment Loss: minimizes distance to semantic neighborhood centroid in the top-k PCA dimensions, ensuring the embedding stays in the correct broad category
- Fine Separation Loss: maximizes distance to confusable class embeddings in the bottom-m PCA dimensions, ensuring the embedding is distinguishable from visually similar alternatives
- The optimized embedding is a drop-in replacement for the original text embedding, requiring no retraining of the visual encoder or re-indexing of the image database
- Semantic neighborhood defines "what this class is broadly" while confusable set defines "what this class must not be confused with"
- LiteEmbed is particularly effective for rare classes where CLIP's text embedding is poorly calibrated due to limited training data for that specific category
