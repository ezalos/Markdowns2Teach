Context:
This diagram illustrates the Deep Sets theoretical framework for a research paper on multi-query embedding search methods for production visual retrieval. The diagram should be clear, academic, and publication-quality. Deep Sets provides the mathematical foundation for understanding why and how set-input functions (functions that take an unordered collection of vectors as input) can be decomposed into a universal architecture. This framework unifies all the query expansion and multi-vector scoring methods discussed in the paper under a single theoretical umbrella.

Elements to represent:
1. Deep Sets theorem statement — The foundational result, presented as a prominent box or banner. The theorem states: any function f that is invariant to the permutation of its inputs (i.e., f of the set {x_1, ..., x_n} gives the same output regardless of the ordering of the x_i) can be decomposed as f({x_1, ..., x_n}) = rho(sum over i of phi(x_i)). Here phi is a transformation applied independently to each element, the sum is a commutative aggregation that ensures permutation invariance, and rho is a transformation of the aggregated result. This decomposition is universal: any continuous permutation-invariant function can be approximated arbitrarily well in this form.
2. Phi transformation — The element-wise function applied independently to each input vector. Show this as a box or module that each input x_i passes through individually. Phi maps each D-dimensional input to a potentially different intermediate representation. In the simplest case (mean aggregation), phi is the identity function. In more powerful variants, phi is a learned neural network that extracts relevant features from each element before aggregation.
3. Commutative aggregation (sum) — The aggregation operator that combines all transformed elements. Shown as a summation node collecting all phi(x_i) outputs. The key property is commutativity: the order in which elements are added does not affect the result, which is what guarantees permutation invariance. Alternatives to sum include mean, max, or any other commutative and associative operation. The choice of aggregation determines the information preserved: sum preserves total magnitude, mean normalizes by count, max captures the most extreme feature.
4. Rho transformation — The output function applied to the aggregated representation. Show this as a final processing block that maps the aggregated vector to the desired output (in our case, an expanded query vector or a relevance score). In the simplest case, rho is the identity or L2 normalization. In powerful variants, rho is a learned neural network.
5. Mapping of Rocchio to the framework — An annotation or row in a comparison table showing that Rocchio corresponds to: phi equals the identity function (each vector is used as-is), aggregation equals weighted mean (alpha, beta, gamma weights on query, positive mean, negative mean), rho equals L2 normalization. This is the simplest non-trivial instantiation of Deep Sets.
6. Mapping of alphaQE to the framework — AlphaQE corresponds to: phi equals multiplication by sim(q, x_i) raised to alpha (each vector is similarity-weighted), aggregation equals sum, rho equals L2 normalization. The phi function here depends on the query, making it a conditional Deep Set.
7. Mapping of SVM (DQE) to the framework — The SVM approach corresponds to: phi equals the identity, aggregation equals the SVM optimization procedure (which is technically not a simple sum but produces a weight vector w from the support vectors), rho equals using w as the query direction. This is a discriminative variant where aggregation is optimization-based rather than arithmetic.
8. Mapping of LAttQE to the framework — LAttQE corresponds to: phi equals a learned attention-based transformation that considers all other elements (via self-attention), aggregation equals attention-weighted sum, rho equals L2 normalization. Self-attention makes phi context-dependent: each element's transformation depends on all other elements, giving this the most expressive phi in the family.
9. Three families diagram — A visual grouping of all methods into three families. Centroid-based family: Rocchio, AQE, alphaQE (simple phi, arithmetic aggregation, normalization rho). Discriminative family: Linear SVM / DQE (identity phi, optimization-based aggregation). Learned fusion family: LAttQE, Set Transformer (learned phi, learned aggregation, learned rho).

Hierarchy:
- Principal: The phi-sum-rho decomposition shown as a clear three-stage pipeline, with input set elements flowing through phi individually, converging at the sum, and emerging through rho. This structural decomposition should dominate the visual layout.
- Secondary: The mapping table or comparison showing how each method (Rocchio, alphaQE, SVM, LAttQE) instantiates the phi, sum, and rho components differently. The three families grouping.
- Optional: The full theorem statement in mathematical notation. Note about the Set Transformer extending Deep Sets with multi-head self-attention. Note about universality (any permutation-invariant function can be approximated).

The diagram has two layers. The top layer shows the general Deep Sets architecture flowing left to right: a set of input vectors {x_1, x_2, ..., x_n} enters on the left, each passes through a phi box independently, the outputs converge at a summation node in the center, and the aggregated result passes through rho on the right to produce the final output. The bottom layer is a comparison table or set of parallel rows, each showing how a specific method (Rocchio, alphaQE, SVM, LAttQE) instantiates the three components. Annotations:
- Deep Sets theorem: f({x_1, ..., x_n}) = rho(sum_i(phi(x_i))) for any permutation-invariant continuous function f
- Phi: element-wise transformation (identity, similarity weighting, learned network, or self-attention)
- Sum: commutative aggregation ensuring permutation invariance (sum, mean, max, or optimization)
- Rho: output transformation (identity, L2 normalization, or learned network)
- Rocchio: phi = identity, aggregation = weighted mean, rho = L2 normalize
- AlphaQE: phi = sim(q, x)^alpha scaling, aggregation = sum, rho = L2 normalize
- DQE/SVM: phi = identity, aggregation = SVM optimization, rho = use weight vector w
- LAttQE: phi = self-attention (context-dependent), aggregation = attention-weighted sum, rho = L2 normalize
- Three families: centroid-based (simple phi), discriminative (optimization aggregation), learned (neural phi and rho)
- Universality: with sufficiently expressive phi and rho, any permutation-invariant function over sets can be represented
