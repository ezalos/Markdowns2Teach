Context:
This diagram illustrates Learned Attention Query Expansion (LAttQE) for a research paper on multi-query embedding search methods for production visual retrieval. The diagram should be clear, academic, and publication-quality. LAttQE replaces the hand-crafted weighting schemes of traditional query expansion methods with a learned self-attention mechanism, enabling the model to assign non-monotonic weights to retrieved neighbors and thereby handle false positives at high ranks.

Elements to represent:
1. Input sequence construction — The first step, shown on the left. The original query vector q and its top-K retrieved neighbors d_1 through d_K are stacked as a sequence of K plus 1 vectors, each of dimension D (768 for SigLIP2). This sequence is formatted as a matrix of shape (K+1) by D, analogous to a sequence of tokens in a transformer. The query occupies position 0 and the neighbors occupy positions 1 through K, ordered by their initial retrieval similarity.
2. Self-attention transformer block — The core computational element in the center. The input sequence passes through one or more self-attention layers. Each element attends to every other element in the sequence, computing attention weights via the standard query-key-value mechanism: Attention equals softmax of (Q times K transposed divided by the square root of d_k) times V. The self-attention allows each neighbor to be evaluated in context: a neighbor that is dissimilar to the consensus of other high-ranked neighbors can be identified as a likely false positive.
3. Attention weight matrix — A K+1 by K+1 matrix visualization showing the learned attention patterns. The critical row is the query's attention over the neighbors, which determines how much each neighbor contributes to the expanded query. Unlike traditional QE methods where weights decrease monotonically with rank, the attention weights can be non-monotonic: a neighbor at rank 3 might receive higher weight than a neighbor at rank 1 if the rank-1 item appears to be a false positive (dissimilar to the consensus of other neighbors).
4. Non-monotonic weight assignment — A bar chart or weight visualization comparing traditional QE weights (monotonically decreasing: rank 1 gets highest weight, rank K gets lowest) with LAttQE weights (non-monotonic: some high-ranked items get low weight if they are outliers, some mid-ranked items get high weight if they reinforce the consensus). This contrast is the key insight of LAttQE. Show a specific example: rank 1 neighbor is a false positive and receives low attention weight, while ranks 2 through 4 receive high weights because they agree with each other.
5. Weighted aggregation — The attention-weighted sum of neighbor vectors (and potentially the query itself) produces the expanded query. This is a standard attention output: the values are the neighbor embeddings, weighted by the learned attention scores. The result is L2-normalized.
6. Expanded query output — The final expanded query vector q_expanded, shown on the right. This vector incorporates information from the most relevant neighbors while suppressing false positives, producing a more accurate search direction for the second retrieval pass.
7. Unification with prior methods — A summary table or annotation showing how LAttQE generalizes previous QE methods. AQE (Average Query Expansion) uses uniform weights (1/K for each neighbor). AlphaQE uses similarity-raised-to-alpha weights. DQE (Discriminative Query Expansion via SVM) uses the SVM weight vector. LAttQE learns the optimal weighting via attention, subsuming all of these as special cases when the attention patterns happen to match their fixed weighting schemes.

Annotations:
- Self-attention: Attention(Q, K, V) = softmax(Q * K^T / sqrt(d_k)) * V, applied to the sequence [q, d_1, ..., d_K]
- Key advantage: attention weights are non-monotonic, allowing the model to detect and suppress false positives at any rank position
- False positive detection mechanism: a neighbor that is dissimilar to the consensus of other retrieved items receives low attention weight even if it was ranked highly in the initial retrieval
- Unification: AQE = uniform attention (1/K), alphaQE = similarity^alpha attention, DQE = SVM-derived attention, LAttQE = learned attention
- Training: LAttQE requires a training set of queries with known relevant items to learn the attention parameters via a retrieval-based loss function
- The model learns to perform implicit relevance estimation within the attention mechanism, effectively learning which neighbors are trustworthy
