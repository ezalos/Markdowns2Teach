Context:
This diagram illustrates Reciprocal Rank Fusion (RRF) for a research paper on multi-query embedding search methods for production visual retrieval. The diagram should be clear, academic, and publication-quality. RRF is a late fusion technique that combines ranked result lists from multiple retrieval systems operating in entirely different embedding spaces, using only rank positions rather than raw scores, thereby avoiding the need for score normalization across incompatible similarity metrics.

Elements to represent:
1. SigLIP2 retrieval pipeline — The first retrieval system, shown as a vertical pipeline on the left side. SigLIP2 produces 768-dimensional embeddings optimized for semantic similarity between text and images. Given a query (text or image), it retrieves the top-N candidates ranked by cosine similarity. The output is an ordered list of candidate identifiers with their ranks. SigLIP2 excels at capturing semantic meaning (what the image is about, matching text descriptions) but may miss fine-grained visual details.
2. DINOv3 retrieval pipeline — The second retrieval system, shown as a parallel vertical pipeline on the right side. DINOv3 (a self-supervised vision transformer) produces embeddings that capture fine-grained visual structure: textures, shapes, spatial arrangements, and subtle visual patterns. It operates in its own embedding space with its own dimensionality and similarity metric. The ranked list from DINOv3 emphasizes visual similarity rather than semantic category matching.
3. Ranked result lists — Two ordered lists emerging from the two pipelines, each showing candidate identifiers with their rank positions (rank 1, rank 2, rank 3, and so on). Some candidates appear in both lists at different rank positions (indicating cross-model agreement), while others appear in only one list. Color-coding or highlighting shows shared candidates between the two lists.
4. RRF scoring formula — The fusion mechanism applied to each candidate. For a given candidate, its RRF score is the sum over all rankers of one divided by (k plus rank_i), where k is a smoothing constant (typically 60) and rank_i is the candidate's rank in ranker i. If a candidate does not appear in a ranker's list, it receives no contribution from that ranker. The constant k prevents top-ranked items from dominating excessively: at k equals 60, rank 1 scores one over 61 (approximately 0.0164), while rank 60 scores one over 120 (approximately 0.0083), only a two-to-one ratio.
5. Consensus reward illustration — A visual callout showing that a candidate ranked first in both systems receives a combined RRF score of approximately 0.0328 (two times one over 61), while a candidate ranked first in only one system gets only approximately 0.0164. This two-to-one ratio demonstrates how RRF rewards agreement between rankers without requiring their scores to be on the same scale.
6. Merged ranked output — The final fused result list on the right or bottom, with candidates reordered by their RRF scores. Candidates appearing highly in both input lists naturally rise to the top of the merged output. Candidates appearing highly in only one list are ranked lower but still included.
7. Late fusion flexibility annotation — A note emphasizing that because RRF operates on ranks rather than embeddings, the two retrieval systems can be queried independently. For a text-only query, the system can query SigLIP2 (which handles text-to-image) without needing DINOv3. For an image-only query, both systems can run. This flexibility is a key advantage of late fusion over early fusion approaches that require embedding-space compatibility.

Each pipeline produces a ranked list of candidates shown as numbered rows. Annotations:
- Formula: RRF_score(d) = sum over rankers r of 1 / (k + rank_r(d))
- Smoothing constant k = 60 (standard value from the original Cormack et al. 2009 paper)
- Rank-based fusion requires no score normalization: cosine similarity from SigLIP2 and L2 distance from DINOv3 need not be compared directly
- Consensus example: candidate at rank 1 in both systems scores 2 / 61 approximately equals 0.0328; candidate at rank 1 in one system only scores 1 / 61 approximately equals 0.0164
- Late fusion advantage: each retrieval system can be queried independently (text-only via SigLIP2, image-only via both, or multimodal), making the architecture modular and extensible to additional embedding models
- Adding a third or fourth ranker (e.g., a color histogram or a domain-specific model) requires only appending another term to the RRF sum
